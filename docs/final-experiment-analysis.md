# Once与Interval：480次实验最终分析

分析日期：2026-11-07T04:21:04.292922+00:00。实验于2026-11-06 10:14 UTC（柏林11:14）结束。

**全部480次计划运行已结束并有评分记录：471次正常提交，9次推理硬超时；原始评分412/480解决。**
其中471次创建了官方判题容器，9次超时无提交按空补丁未解决计分。全部已创建判题容器均审计为network=none。
另有1条正常提交的Gson因Maven守护进程连接超时未执行目标测试；原评分保留为false，单列环境未决，不能解释为补丁语义错误。

## 1. 主要结论

- **Once主要节省首次定位搜索，未稳定减少全程搜索。** 相对同阶段plain，1024/2048/4096的配对全程搜索变化为+5.1%/−5.0%/+5.3%，探索性95%区间均跨0。
- **Interval减少全程搜索的证据更一致。** 三档相对同阶段plain分别减少12.1%/11.0%/16.1%；任务簇重采样的探索性95%区间均低于0。4096在三轮中的搜索差值均为负。
- **不能宣称成功率已证明非劣效。** interval原始通过数54/54/53对plain的53，观察上未下降；只看双方均有效的配对则为53=53、53=53、52<53。全部成功率差值的95%区间均跨0。
- **动态地图的已返回费用明显更高。** interval地图组约为同预算once的3倍，输入token缓存占比约10.6%–15.0%，once约86.4%–89.9%；费用还受请求数量与输入/输出量影响，不能只归因于缓存。
- **不能把跨阶段差异全部归因于刷新频率。** once用原始任务，interval用任务+最近6条消息；两个阶段顺序执行，plain本身也出现差异。做基线调整后，跨策略搜索差值的区间仍全部跨0。

在这批样本中，interval4096是进一步验证“减少搜索”的候选；interval1024费用较低、观察通过数较高，是折中候选。当前没有通用最优预算或可靠的仓库长度阈值。

## 2. 协议、计数与不确定性

20个仓库各1条任务；once/interval两个阶段，每阶段0/1024/2048/4096四档，每档重复3次，即每条件60次。模型始终为`openrouter/deepseek/deepseek-v4.1-flash-1017`；全部10640条已计费响应的实际模型标识一致。
容器断网、镜像固定、模型与运行限制一致。扫描上限为20000文件、单文件1GiB、源码总量128MiB；模型调用保持mini累计历史。once固定地图在后续历史中仍会发送；interval每轮替换一张地图。
地图预算按cl100k_base编码，费用采用模型服务端实际usage，不将两种token口径混同。本轮使用mini适配版生成器，未运行Aider原版、auto或动态预算对照。

- Search Calls per Task：显式Bash搜索子命令，包含grep/rg、文件定位及日志过滤，不含普通cat/sed、脚本内部搜索和地图扫描。统计请求，不保证所有条件分支执行。
- 搜索调用减少只代表模型显式发出的搜索更少；本指标不计地图内部扫描，因此不能据此认定总仓库I/O、计算量、读取信息量或耗时减少。
- Target Localization Cost：首次显式读取官方基线目标区域，整体工具动作退出0且模型可见输出包含参考源码。累计搜索包含定位动作；未观察到为null，不作0。它不测量模型心智、完整修复范围或地图实际利用。
- Resolved Rate：主表分母包含全部60次计划运行，超时无提交计未解决；另列有效运行配对敏感性。
- 全程搜索主均值只覆盖正常结束的有效推理，附有效分母；超时轨迹不当成低搜索收益。对照效果使用同任务、同重复编号的有效配对。
- 95%区间：固定种子20261107，10000次按任务簇重采样，某任务的全部可用重复一起抽取。没有把60次视作60个独立任务；区间只描述这些任务与可观察运行，未作多重比较校正，不证明一般性收益或非劣效。
- 原报告部分`provisional=true`是因为有效样本未满60，不表示队列仍运行。本次所有计划均已结束；不静默改写冻结报告。

## 13. 与此前实验的关系

最初单次once1024为17/20、plain为15/20，搜索增加10.0%。新三轮同预算once为14/17/17，plain为16/18/17；初始地图与原1024地图保持一致，但没有复现稳定成功率优势。旧Lucene当时未执行目标测试，本轮已修复，不能把新通过直接归功于地图。
旧四档interval单次结果为plain16/20、1024为16、2048为16、4096为17；对应搜索234/197/242/222。本轮重复数据中三档相对同阶段plain均减少搜索，但4096不再有通过数优势。一次运行的最佳预算并非重复后的稳定赢家。
此前120条轨迹补算的定位成本亦显示“定位节省与总搜索不同”：预算2048定位搜索减少27.5%，当时全程搜索却增加3.4%。本轮once1024/4096的分解进一步印证了这种区别。
